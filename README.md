# OTTweaks.com

The OT Tweaks website, served by GitHub Pages at https://ottweaks.com.

- `config.js` - Stripe link, price, Discord, download source
- `index.html` - homepage
- `thanks.html` - shown after payment (download button)
- `download.html` - ottweaks.com/download (starts the newest installer from GitHub Releases)
- `discord.html` - ottweaks.com/discord redirect
